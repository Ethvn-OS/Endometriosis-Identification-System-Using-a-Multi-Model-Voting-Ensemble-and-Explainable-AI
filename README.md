# Endometriosis-Identification-System-Using-a-Multi-Model-Voting-Ensemble-and-Explainable-AI
A deep learning framework for endometriosis identification using pelvic MRI scans. It combines ResNet50, EfficientNetV2, and DenseNet121 through soft voting, with Grad-CAM for explainability. The study evaluates classification performance using accuracy, precision, sensitivity, F1-score, and AUC-ROC.
