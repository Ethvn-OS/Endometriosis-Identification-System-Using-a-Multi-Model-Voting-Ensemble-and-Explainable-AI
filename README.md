# Endometriosis-Identification-System-Using-a-Multi-Model-Voting-Ensemble-and-Explainable-AI
Endometriosis is a chronic gynecological disease that is often diagnosed years after symptom onset because of nonspecific clinical manifestations and the limitations of existing diagnostic approaches. This study aims to develop and evaluate a multi-model soft voting ensemble deep learning approach integrated with Explainable Artificial Intelligence for endometriosis identification using pelvic MRI scans. The proposed framework utilizes transfer learning with three convolutional neural network architectures (ResNet50, EfficientNetV2, and DenseNet121) combined through a soft voting ensemble to improve classification performance. Pelvic MRI scans obtained from publicly available datasets and a collaborating local hospital undergo preprocessing, standardization, augmentation, and partitioning prior to model training and evaluation. Model performance is assessed using accuracy, precision, sensitivity, F1-score, and Area Under the Receiver Operating Characteristic Curve (AUC-ROC), while Gradient-weighted Class Activation Mapping (Grad-CAM) is employed to visualize the image regions influencing model predictions. The proposed ensemble models are anticipated to achieve higher classification performance than individual CNN architectures. Furthermore, the generated Grad-CAM visualizations are expected to improve model interpretability by highlighting clinically relevant anatomical regions, demonstrating the potential of the proposed framework as a reliable clinical decision-support tool for non-invasive endometriosis identification.
